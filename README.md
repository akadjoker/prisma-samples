# prisma samples

Small programs that each show one thing the [prisma](https://github.com/akadjoker/prisma) driver can do. They run on OpenGL 4.6, OpenGL ES 3 and Vulkan: add `vulkan` to the command line for Vulkan, a number to stop after that many frames, and `still` to freeze time.

The demos that load meshes and textures read them from a media folder: set the environment variable `PRISMA_MEDIA` or the CMake option `PRISMA_MEDIA_DIR`. A demo whose feature is missing on the GPU prints a line and exits.

## Building

The project depends on [prisma](https://github.com/akadjoker/prisma), [zen_plataform](https://github.com/akadjoker/zen_plataform) and [math](https://github.com/akadjoker/math), all as submodules.

```sh
git clone --recursive https://github.com/akadjoker/prisma-samples
cd prisma-samples
cmake -S . -B build -DPRISMA_MEDIA_DIR=/path/to/Media -DPRISMA_MODELS_DIR=/path/to/models
cmake --build build
ctest --test-dir build
```

`glslangValidator` (or `glslang`) must be installed; SPIRV-Cross is built from prisma's submodule when `spirv-cross` is not on the path. `SAMPLES_BUILD_TESTS=OFF` skips the tests of the shared code. The demos are written to `build/<name>`.

## In the browser

`./web.sh` builds the demos of `web_demos.txt` with Emscripten for WebGL 2 and copies each to `web-out/<name>/` (`.html`, `.js`, `.wasm` and `.data`). It needs the Emscripten SDK on the path (`source emsdk_env.sh`), glslangValidator, a native build of the project (the shader tool spirv-cross is taken from its build folder) and the media folder. The files a demo reads are listed in its `web_media.txt` and packed with the page; the demo loop is suspended once per frame with Asyncify until the next animation frame of the browser. WebGL 2 has no compute, tessellation or geometry shaders, so the demos that need them (12, 16, 17, 21 to 27, 29, 38) only print a line and stop. Ten demos run today: 01, 02, 03, 04, 05, 09, 10, 11, 28 and 37.

## Running every demo

`./run_all.sh [build-dir] [frames] [backend]` configures the build directory if it does not exist, builds everything and runs each demo for the given number of frames (default 120, backend `vulkan` or empty for OpenGL); it prints a summary and exits with an error if any demo failed. Pointed at the windowless build described below it runs without opening any window.

## Screenshots without a window

The pictures above are taken by the demos themselves, with no window system: configure a tree whose window library is a stub and whose driver draws into an off-screen surface on the real GPU, then run the script.

```sh
cmake -S . -B build-shots -DSAMPLES_HEADLESS=ON -DSAMPLES_BUILD_TESTS=OFF
cmake --build build-shots
./shots.sh build-shots images
```

Any demo also saves a picture of the frame it is drawing when `PRISMA_SHOT=file.png` is set (and `PRISMA_SHOT_FRAME=n` picks the frame), in a normal window build too.
